# Quantity Measurement App

## Overview

The **Quantity Measurement App** is designed to compare and convert different physical quantities such as **length**, **weight**, and other measurable units.

The application will be developed incrementally, with each stage introducing new functionality while maintaining a clear and manageable scope.

## Features

### Phase 1: Quantity Comparison
- Compare two quantities of the same type.
- Support multiple units within a measurement category (e.g., length, weight).
- Determine whether two quantities are equal after unit conversion.

### Phase 2: Unit Conversion
- Convert a quantity from one unit to another.
- Support conversions within the same measurement category.
- Display accurate conversion results.

### Phase 3: Quantity Arithmetic
- Perform arithmetic operations on compatible quantities.
- Support operations such as:
  - Addition
  - Subtraction
- Ensure automatic unit conversion where required before performing calculations.

## Development Approach

The application follows an **incremental development** approach.

Each use case defines a **specific scope**, allowing features to be implemented, tested, and refined independently.

> **Note:** Avoid implementing functionality beyond the current use case. Keeping the scope focused helps maintain the application's simplicity, reliability, and maintainability.

## Goal

Build a robust and extensible Quantity Measurement application that progressively evolves from:

1. Quantity Comparison
2. Unit Conversion
3. Quantity Arithmetic

while ensuring clean design, maintainability, and testability.
